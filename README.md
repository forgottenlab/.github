# ForgottenLab Engineering Standards

[English](README.md) | [简体中文](README.zh-CN.md)

A lightweight, bilingual Git and GitHub engineering handbook maintained by ForgottenLab.

These are practical recommendations for personal development, learning, and possible future collaboration—not mandatory organizational procedures.

## Documentation

- [Engineering Handbook (English)](docs/standards/README.md)
- [工程手册（简体中文）](docs/standards/README.zh-CN.md)
- [Contributing / 贡献指南](CONTRIBUTING.md)

## Principles

- Start from real problems.
- Keep everyday development simple.
- Use Issues, Pull Requests, and automation when useful.
- Prefer safe, understandable, and maintainable changes.
- Improve practices through actual experience.

This repository also provides lightweight GitHub Issue Forms and a Pull Request template.
