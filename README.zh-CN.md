## 🧭 工程理念

- 从真实问题出发。
- 保持日常开发流程简单，默认更安全。
- 先解释再执行，先备份再修改。
- 先测试再发布，写文档给未来的自己。
- 按需使用 Issues、Pull Requests 和自动化。
- 优先考虑安全、可理解与可维护性。
- 根据实际开发经验持续改进。

本仓库还提供轻量的 GitHub Issue Forms 和 Pull Request 模板。
